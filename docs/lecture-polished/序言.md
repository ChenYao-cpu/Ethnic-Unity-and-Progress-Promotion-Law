# 序言

同学们好。今天我将为大家系统讲解《中华人民共和国民族团结进步促进法》。这部法律于2026年3月12日由第十四届全国人民代表大会第四次会议高票通过，习近平主席签署第七十一号主席令予以公布，自2026年7月1日起正式施行。

本法采用"序言加七章"的体例结构，共六十五条，是三十多年来我国第一部设置序言的新制定法律，充分体现了统摄性、纲领性的基本法律地位。序言首次将习近平总书记关于加强和改进民族工作的重要思想写入法律，为全法确立了根本遵循。

我国是统一的多民族国家，中华民族拥有五千多年文明史。在长期的历史进程中，各族人民共同开拓了祖国的辽阔疆域，共同缔造了统一的多民族国家，共同书写了悠久的中国历史，共同创造了灿烂的中华文化，共同培育了伟大的民族精神，凝聚成了血脉相融、信念相同、文化相通、经济相依、情感相亲的命运共同体。这"五个共同"深刻揭示了中华民族多元一体的历史格局，体现了中华民族强大的凝聚力与向心力。

1840年鸦片战争以后，封建中国逐渐沦为半殖民地半封建社会。在国家蒙辱、人民蒙难、文明蒙尘的危难时刻，各族人民始终坚守国土不可分、国家不可乱、民族不可散、文明不可断的坚定信念。在救亡图存的伟大斗争中，这一信念驱动各族人民团结一心、共赴国难，实现了中华民族从自在到自觉的伟大转变，彰显了强大的民族凝聚力与向心力。

中国共产党作为中国工人阶级的先锋队、中国人民和中华民族的先锋队，以谋求人民幸福、实现民族复兴为初心使命。在党的领导下，各族人民经过艰苦卓绝的斗争，实现了民族独立和人民解放，建立了中华人民共和国，使各族人民真正成为国家的主人。新中国成立以来，中国共产党团结带领各族人民共同奋斗、共同繁荣发展，走出了一条中国特色解决民族问题的正确道路，中华民族迎来了从站起来、富起来到强起来的伟大飞跃。

进入新时代，以习近平同志为核心的党中央将马克思主义民族理论同中国具体实际相结合、同中华优秀传统文化相结合，明确把铸牢中华民族共同体意识作为新时代党的民族工作的主线和民族地区各项工作的主线，形成了习近平总书记关于加强和改进民族工作的重要思想，开辟了马克思主义民族理论中国化时代化的新境界，推动中华民族共同体建设取得历史性成就、发生历史性变革。

中华民族是多元一体的大家庭。民族团结是我国各族人民的生命线，关乎国家的长治久安和中华民族的伟大复兴。全国各族人民、一切国家机关和武装力量、各政党和各社会团体、各企业事业组织，都应当以铸牢中华民族共同体意识为主线，依照宪法和法律规定，维护和发展平等团结互助和谐的社会主义民族关系，以中华民族大团结促进中国式现代化，为实现中华民族伟大复兴而团结奋斗。
