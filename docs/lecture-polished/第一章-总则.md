# 第一章 总则（第一条—第十条）

各位同学好。今天我们来学习《中华人民共和国民族团结进步促进法》的第一章——总则。总则作为整部法律的纲领，全面贯彻了习近平总书记关于加强和改进民族工作的重要思想"十二个必须"的核心要义，为新时代民族团结进步事业提供了根本遵循和法治保障。总则共十条，按四个层次展开：第一层（第一、二条）落实宪法规定，明确党的领导和指导思想；第二层（第三、四条）阐释核心概念；第三层（第五至七条）规定重要原则；第四层（第八至十条）规定基本制度。

**第一条：立法目的与依据。** 本法以宪法为根本依据，立法目的分为四个递进层次——促进民族团结进步、铸牢中华民族共同体意识、推进中华民族共同体建设、推动实现中华民族伟大复兴。宪法序言及第四条关于"中华人民共和国各民族一律平等""国家维护和发展各民族的平等团结互助和谐关系"等规定，是本法的根本法律依据。本法属于宪法相关法，是实施宪法有关规定、处理民族事务和开展民族工作的基本法律。

**第二条：指导思想。** 本条确立民族团结进步事业的根本政治原则和思想遵循。民族团结进步事业坚持中国共产党的全面领导——这是最高政治原则；高举中国特色社会主义伟大旗帜，完整贯彻马克思列宁主义、毛泽东思想、邓小平理论、"三个代表"重要思想、科学发展观，全面贯彻习近平新时代中国特色社会主义思想；坚定不移走中国特色解决民族问题的正确道路，为强国建设、民族复兴凝聚磅礴力量。

**第三条：铸牢中华民族共同体意识。** 本条对全法的核心概念作出法定阐释。铸牢中华民族共同体意识，应当引导各族人民牢固树立休戚与共、荣辱与共、生死与共、命运与共的共同体理念。"四个与共"从利益共同体、价值共同体、安全共同体、命运共同体四个维度，定义了中华民族共同体的内在联结，最终目标是增强中华民族凝聚力。

**第四条：推进中华民族共同体建设。** 本条明确要统筹经济建设、政治建设、文化建设、社会建设和生态文明建设五大领域，实现各民族共同繁荣发展，确保各族人民共同当家做主人，构筑中华民族共有精神家园，促进各民族全方位互嵌和广泛交往交流交融，共同守护人与自然和谐共生的生态家园，推动中华民族成为认同度更高、凝聚力更强的命运共同体。

**第五条：民族平等原则。** 中华人民共和国公民在法律面前一律平等，中华人民共和国各民族一律平等。本条严格禁止对任何民族的歧视和压迫，将宪法关于民族平等的规定具体化、制度化，是我国民族政策的根本底线。

**第六条：民族团结之本。** 本条作出重要定性：中华民族共同体意识是民族团结之本。国家坚持增进共同性、尊重和包容差异性，促进各民族守望相助、和谐共处。同时划定法律红线：禁止破坏民族团结和制造民族分裂的行为。根据立法解读，"增进共同性、尊重和包容差异性"是本法的核心方法论原则。

**第七条：共同团结奋斗、共同繁荣发展。** 国家坚持"两个共同"的基本方针，推动物质文明、政治文明、精神文明、社会文明、生态文明协调发展，全面推进中华民族发展进步，让各族群众共享改革发展成果，朝着共同富裕的目标稳步前进。

**第八条：民族区域自治制度。** 国家坚持和完善民族区域自治制度，维护国家统一和民族团结。民族区域自治制度是我国的一项基本政治制度，体现了统一和自治相结合、民族因素和区域因素相结合的原则。需要特别强调的是，区域自治是在国家统一前提下的自治，绝非民族自决或独立。

**第九条：依法治理民族事务。** 国家坚持运用法治思维和法治方式治理民族事务，依法保障各族群众合法权益，加强宪法法律宣传教育，增强各族群众的国家意识、公民意识、法治意识，维护社会主义法治的统一、尊严和权威，在法治轨道上推进民族事务治理体系和治理能力现代化。

**第十条：公民义务与域外适用。** 本条确立两个重要原则。一是中华人民共和国公民有维护国家统一和全国各民族团结的法定义务，应当维护国家主权、安全、发展利益。二是我国的民族团结进步事业不受任何外部势力干涉，坚决反对一切以民族、宗教、人权等借口对中华人民共和国实施污蔑抹黑、遏制打压、渗透破坏的行为。本条的域外效力体现了国家维护统一和民族团结的坚定法律意志。

总则的十条内容，从立法目的到指导思想，从核心概念到基本原则，从制度安排到公民义务，层层递进、环环相扣，为后续各章提供了坚实的法理基础。下一节课我们将学习第二章"构筑共有精神家园"。谢谢大家。
