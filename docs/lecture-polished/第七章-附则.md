# 第七章 附则（第六十四条—第六十五条）

同学们好。今天我们学习本法最后一章——第七章"附则"。附则虽然只有两条，但涉及法律实施的两个关键问题：地方立法授权和法律生效时间。

**第六十四条：地方立法授权。** 省、自治区、直辖市和设区的市、自治州人民代表大会及其常务委员会，可以结合当地实际情况，制定促进民族团结进步的地方性法规。这是一项重要的授权性条款，赋予地方因地制宜的立法空间。

本条的意义在于：第一，我国幅员辽阔，各民族分布情况和民族关系各有特点，地方立法能够更好地回应本地实际需求；第二，设区的市和自治州被纳入授权范围，体现了立法权的适度下放，有利于基层民族工作的法治化；第三，地方立法必须"结合当地实际情况"，不得与国家法律相抵触，确保国家法治的统一。

**第六十五条：施行日期。** 本法自2026年7月1日起施行。这一施行日期的确定，为法律实施前的准备工作留出了充分的准备期，各相关主体应当在此期间内做好法律学习、宣传、配套制度制定等准备工作，确保法律顺利实施。
