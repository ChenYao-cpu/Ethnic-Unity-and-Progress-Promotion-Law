# 第二章 构筑共有精神家园（第十一条—第二十一条）

同学们好。今天我们来学习第二章"构筑共有精神家园"。本章是本法最具创新性的章节之一，从价值观引领、历史认知、文化认同、语言文字、学校教育、理论研究、社会教育、媒体传播、家庭教育到港澳台与海外，形成一个由内而外、从观念到制度的完整体系，旨在增强全体中华儿女的文化认同和中华民族凝聚力。

**第十一条：社会主义核心价值观引领。** 国家坚持以社会主义核心价值观为引领，深化爱国主义、集体主义、社会主义教育，引导各族群众弘扬以爱国主义为核心的民族精神和以改革创新为核心的时代精神，坚定对伟大祖国、中华民族、中华文化、中国共产党、中国特色社会主义的认同。这"五个认同"是构筑共有精神家园的核心目标，体现了国家认同、民族认同、文化认同、政党认同和道路认同的高度统一。

**第十二条：历史观教育。** 国家组织开展党史、新中国史、改革开放史、社会主义发展史、中华民族发展史的"五史"宣传教育，引导各族群众牢固树立正确的国家观、历史观、民族观、文化观、宗教观。这"五观"是科学认识中华民族发展历程的思想基础。同时，公民应当增强国家观念，传承和弘扬爱国主义精神，维护国旗、国歌、国徽等国家象征和标志的尊严。

**第十三条：文化传承与中华文化认同。** 国家发展社会主义先进文化，弘扬革命文化，传承中华优秀传统文化。本条明确宣示：各民族优秀传统文化都是中华文化的组成部分。国家坚持以社会主义先进文化引领各民族优秀传统文化的创造性转化和创新性发展，加强文物和非物质文化遗产保护，增进中华文化认同，增强中华文化自信。这体现了中华文化与各民族文化之间"主干与枝叶"的辩证关系。

**第十四条：中华文化符号与中华民族形象。** 国家树立和突出各民族共有共享的中华文化符号和中华民族形象，依托中华民族的文化和自然遗产等资源，推动中华文明标识体系的构建。公共设施等的建设和改造应当展示中华文化符号与中华民族形象。同时，公民应当维护中华民族形象，不得进行侮辱、贬损和亵渎。这一规定将文化认同从抽象理念转化为具体可感的符号载体。

**第十五条：国家通用语言文字。** 本条的核心精神是：推广国家通用语言文字与尊重保障少数民族语言文字并行不悖。一方面，国家全面推广普及国家通用语言文字，学校及其他教育机构以国家通用语言文字为基本的教育教学用语用字，任何组织和个人不得妨碍公民学习和使用；另一方面，国家尊重和保障少数民族语言文字的学习和使用，推动其规范化、标准化和信息化建设，支持少数民族古籍的保护、整理、研究和利用。根据立法解读，这体现了增进共同性和尊重差异性的辩证统一。

**第十六条：学校教育。** 各级各类学校及其他教育机构应当将铸牢中华民族共同体意识的要求贯穿教育全过程，融入课堂教学、社会实践、主题教育和网络教育相结合的教育体系，按照有关规定使用国家统编教材。这明确了学校在铸牢工作中的主阵地责任，确保共同体意识教育从娃娃抓起。

**第十七条：理论体系建设。** 国家推动构建中国自主的中华民族共同体史料体系、话语体系、理论体系，支持高等学校和科研机构加强对中华民族共同体重大基础性问题的研究，阐释中华民族和中华文明多元一体格局的历史与内涵。这"三大体系"建设为铸牢中华民族共同体意识提供了坚实的学术支撑。

**第十八条：社会教育全覆盖。** 国家将铸牢中华民族共同体意识教育纳入国民教育、干部教育、社会教育三大体系。各级人民政府应当充分利用中华优秀传统文化资源、红色资源和体现中国特色社会主义建设成就的各类资源，因地制宜采取多种形式，广泛开展教育，构建全方位、多层次的共同体意识教育格局。

**第十九条：媒体宣传与国际传播。** 报刊、广播、电视等新闻媒体和出版单位、网络服务提供者应当开展有关铸牢中华民族共同体意识、推进中华民族共同体建设的宣传报道和成就展示。国家推进国际传播能力建设，支持开展对外人文交流，推动文明交流互鉴，提升中华文化国际影响力。

**第二十条：家庭教育。** 各级人民政府应当推动将铸牢中华民族共同体意识的要求融入家庭、家教和家风建设。未成年人的父母或者其他监护人应当依法履行家庭教育责任，教育和引导未成年人热爱中国共产党、热爱祖国、热爱人民、热爱中华民族，树立中华民族一家亲的观念，不得向未成年人灌输不利于民族团结进步的观念。家庭是社会的细胞，本条规定为家庭教育划定了法律底线。

**第二十一条：港澳台与海外。** 本条在国家统一和民族认同方面作出重要安排。一是支持香港特别行政区、澳门特别行政区开展中华民族历史、中华文化和国情教育，引导港澳同胞自觉维护国家主权、安全、发展利益，在国内法意义上完善了"一国两制"方针的法律体系。二是促进两岸经济文化交流合作，深化两岸各领域融合发展，增进台湾同胞对中华民族的归属感、认同感、荣誉感。三是加强同海外侨胞的联系交流，形成海内外中华儿女同心共筑中国梦的生动局面。

第二章从思想引领到制度安排，从学校教育到家庭熏陶，从境内到境外，构建了一个完整的中华民族共有精神家园建设体系。下一节课我们将学习第三章"促进交往交流交融"。谢谢大家。
