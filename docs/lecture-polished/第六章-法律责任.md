# 第六章 法律责任（第五十七条—第六十三条）

同学们好。今天我们来学习第六章"法律责任"。本章建立了完整的追责体系，涵盖国家机关失职、破坏民族团结、民族歧视、单位责任、网络平台责任、严重犯罪和域外适用等七个方面，体现了引导性与约束性并重的立法原则，以刚性约束确保法律落地。

**第五十七条：国家机关失职责任。** 本条规定两种追责情形：一是国家机关及其工作人员不履行或不正确履行本法规定职责的；二是对第五十八条至第六十一条规定的违法行为未及时予以制止并依法予以处理的。追责方式为三阶递进——由其主管部门或者有关机关责令改正；造成不良后果或者影响的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。这体现了"有权必有责、失责必追究"的法治原则。

**第五十八条：破坏民族团结进步的处罚。** 任何组织和个人违反本法有关规定，破坏民族团结进步的，由县级以上人民政府有关部门按照职责及时予以制止、责令改正，并依法给予处罚。构成违反治安管理行为的，由公安机关依法给予治安管理处罚；构成犯罪的，依法追究刑事责任。本条形成了行政处罚→治安管理处罚→刑事追责的完整处罚链条，确保任何破坏行为都受到法律制裁。

**第五十九条：民族歧视行为的处置。** 本条专门针对以民族身份为由实施的就业歧视、拒绝提供商品或者服务，以及法律法规禁止的其他歧视行为。由县级以上民族工作、人力资源和社会保障、市场监管等有关部门按照职责责令改正；造成不良后果或者影响的，予以警告或者通报批评。法律法规另有处罚规定的，从其规定。这一规定与其他法律（如《就业促进法》）实现了有效衔接。

**第六十条：社会组织的制止义务。** 社会团体、企业事业组织和其他社会组织对本单位内发生的破坏民族团结进步的行为，应当及时予以制止——这是法定义务。未及时制止，造成不良后果或者影响的，实行"双罚制"：对单位予以警告或者通报批评，同时对直接负责的主管人员和其他直接责任人员依法追究法律责任。

**第六十一条：网络运营者责任。** 网络运营者违反本法规定，未履行管理责任的，由网信、电信、公安、国家安全、新闻出版、广播电视等有关主管部门按照职责责令改正；拒不改正或者情节严重的，依法给予处罚。本条体现了多部门联合执法，回应了互联网时代民族工作面临的新挑战。

**第六十二条：严重犯罪行为的刑事追责。** 本条是最为严厉的刑罚条款，针对三类严重犯罪：暴力恐怖活动、民族分裂活动、宗教极端活动。不仅组织、策划、实施这些行为构成犯罪的要被追究刑事责任，煽动或者资助实施这些行为构成犯罪的同样要被追究刑事责任。根据立法解读，本条规定体现了国家对危害民族团结和国家统一行为的"零容忍"态度。

**第六十三条：域外适用——"长臂管辖"。** 中华人民共和国境外的组织和个人，针对中华人民共和国实施破坏民族团结进步、制造民族分裂行为的，依法追究法律责任。本条将法律适用范围延伸至境外，为打击境外反华势力的渗透破坏活动提供了明确的法律武器，体现了维护国家统一和民族团结的坚定法律意志。

第六章以"有权必有责、有责必担当、失责必追究"的法治理念，构建了从行政处罚到刑事追责、从境内追责到域外适用的完整法律责任体系，确保《中华人民共和国民族团结进步促进法》真正成为一部"长牙齿"的法律。下一节课我们将学习最后一章——第七章"附则"。谢谢大家。
