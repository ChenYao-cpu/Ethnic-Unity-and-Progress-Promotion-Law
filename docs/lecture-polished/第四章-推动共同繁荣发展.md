# 第四章 推动共同繁荣发展（第三十二条—第四十条）

同学们好。今天我们来学习第四章"推动共同繁荣发展"。本章围绕贯彻新发展理念、推动各民族共同迈向社会主义现代化，从改革开放、区域协调、基础设施、产业体系、公共服务、生态保护、兴边富民到移风易俗，全面部署了推动各民族共同繁荣发展的制度安排。

**第三十二条：高质量发展与共同富裕。** 国家贯彻创新、协调、绿色、开放、共享的新发展理念，支持民族地区全面深化改革开放、全面融入国家发展战略、提升自我发展能力，加快民族地区高质量发展，推进各民族共同富裕，推动各民族共同迈向社会主义现代化。这是共同繁荣发展的总纲和方向。

**第三十三条："三个有利于"标准。** 县级以上人民政府及其有关部门制定和实施经济社会发展领域的规划计划、政策措施，应当有利于铸牢中华民族共同体意识、推进中华民族共同体建设，有利于维护国家统一、反对分裂，有利于改善民生、凝聚人心。根据立法解读，这"三个有利于"要求将所有改革发展赋予彰显中华民族共同体意识的意义，是一切涉民族工作政策制定的核心标尺。

**第三十四条：区域协调发展。** 国家促进区域协调发展，完善区域一体化发展机制和差别化区域支持政策，健全对口支援、东西部协作等帮扶协作机制。国家支持民族地区结合区域主体功能定位，统筹发展和安全，在维护国家边疆安全、资源能源安全、粮食安全和生态安全等方面担起使命责任。同时，助力民族地区融入双循环、共建"一带一路"等国家重大战略。

**第三十五条：基础设施建设。** 国务院有关部门和县级以上地方人民政府应当加强交通、能源、水利、信息、物流等基础设施建设，推进民族地区与其他地区之间的互联互通。基础设施建设是民族地区发展的先决条件，打破地理阻隔才能实现真正的互通共融。

**第三十六条：现代化产业体系。** 国家建设现代化产业体系，因地制宜发展新质生产力，有序推进区域间的产业合作和利益共享机制建设。支持民族地区依托资源禀赋发展农林牧渔等特色优势产业，壮大新型农村集体经济，促进乡村全面振兴与新型城镇化有机结合，在优化区域产业链和供应链布局中充分发挥作用。

**第三十七条：公共服务均等化。** 国务院有关部门和县级以上地方人民政府应当推动就业、教育、医疗等方面公共服务资源的合理配置，增强基本公共服务均衡性和可及性，促进民族地区各级各类教育协调发展，提高民族地区公共服务保障能力，让各族群众共享改革发展成果。

**第三十八条：生态保护与可持续发展。** 国务院有关部门和县级以上地方人民政府应当统筹优化农业、生态、城镇等各类空间布局，加强民族地区的生态环境保护和自然资源的可持续利用，引导各族群众共同维护中华民族永续发展的生态空间。绿水青山就是金山银山，生态保护是实现可持续发展的根基。

**第三十九条：兴边富民、稳边固边。** 国务院有关部门和边境地区县级以上地方人民政府应当统筹推进兴边富民、稳边固边，鼓励支援边境地区建设，推进基础设施和公共服务设施建设，改善边境村落人居环境和生产生活条件。同时加强沿边城镇、开发开放及产业平台建设，支持边境贸易、边境旅游等，确保边境地区繁荣稳定。

**第四十条：移风易俗与婚姻自由。** 本条包含两个重要制度安排。一是推进移风易俗——国家加强时代新风新貌的培育，推进公民道德建设，开展群众性法治宣传教育和科学技术普及，引导各族群众在生活交往、婚丧嫁娶等活动中自觉遵守法律法规、遵循公序良俗。二是婚姻自由保护——国家保护公民婚姻自由，任何组织和个人不得以民族身份、风俗习惯、宗教信仰等为由干涉婚姻自由。根据立法解读，该条款在尊重民族风俗习惯和维护公民基本权利之间划定了明确的法律界限。

第四章从发展理念到具体政策、从经济建设到社会文明，体现了"推动各民族共同繁荣发展"不是一句口号，而是一套完整的制度设计和政策安排。下一节课我们将学习第五章"保障与监督"。谢谢大家。
