# 云疆知法：Web迁移与视觉资源

## 本次交付

- 19个原创功能图标：SVG源文件、TrueType字体、CSS、微信小程序WXSS、Unicode清单。
- 原创“同心云典”标识：云形环抱展开法典，深红与陶红构成连接。
- Web竖版（图形在上、云疆知法在下）、横版、独立图形、小程序圆角方标。
- SVG与透明PNG，方标有1024、512、192、96像素四档。
- 管理员与法务Web工作台，复用现有数据库、服务和审核状态。
- 小程序保留学习入口，原管理员/法务首页变为Web访问引导，旧管理页面源文件保留但不再注册为小程序页面。

## 访问

启动当前Spring Boot项目后：

- 工作台：`http://localhost:8080/console/`
- 图标预览：`http://localhost:8080/console/icons.html`
- 用数据库中已有的admin、teacher或legal_officer账号登录，不能通过前端选择角色获得权限。
- 本机地址仅适合本机。云服务器部署后，小程序`frontend/utils/config.js`的BASE_URL应设置为实际后端地址，管理入口自动使用该服务器的`/console/`。

## 管理员与法务能力

管理员：题库选题、调用现有AI出题接口、创建作业草稿、修改基本信息与题目、提交法务、审核通过后发布、删除作业、查看学习进度、导出实际提交成绩、发送学习提醒；课程创建编辑、封面上传、提交审核、发布、下架、删除。

法务：待审核作业、题目与解析查看、逐题通过/退回及意见保存、完整审核后提交整体结果、审核历史、课程视频查看与课程通过/退回。

题目修改时复制为新题并更新作业关联，避免改动其他作业引用的题目。修改后清除旧审核记录，重新进入草稿。已发布/审核中的作业不能直接修改。提醒写入原reminder表，小程序沿用原提醒接口读取。

多智能体协同尚未实现，Web明确标注待开发。现有AI接口可能包含本地题目回退，不能把该接口每次返回都宣传为实时大模型生成。自动审题与证据溯源不能由图标或页面文案替代真实实现。

## 后端说明

新增ConsoleController提供同源会话与受限接口适配：按数据库角色授权、按创建者校验内容所有权、白名单限制可调用路由、约束审核状态。登录会话30分钟无活动过期。新增ConsolePageController处理`/console/`入口。

当前适配层通过本机回环调用既有接口，并直接处理安全封面上传、题目修订与提醒。既有`/api/*`接口的全局鉴权问题不在本次适配层内解决；上线公网前需统一保护旧接口，不能认为新增工作台会话已经保护整个历史后端。

不增加展示用假账号、假统计或假审核。API加载失败显示错误；无数据则显示空态。

## 视觉规范

主色：#791817。辅助：#D07367。浅色面板：#F0D3CC。背景：#FAF7EB。正文：#302523。次级文字：#796762。

配色参考用户提供的色板。图标路径、Logo图形与工作台布局重新设计，不复制参考图中的剪纸、生肖、山海经图形或版式。仅减少颜色不能证明原创，保留生成脚本和SVG源文件有助于说明设计过程。

19个图标使用独立yunjiang字体，未覆盖原iconfont资源。迁移主要业务图标，原工具类图标继续沿用。`yj-icon yj-study`等类名见manifest.json。小程序WXSS使用字体Base64，避免远程字体请求。

Logo中文字由本机Microsoft YaHei Bold字形转为轮廓，非手写定制字库；字体文件未随Logo分发。AI图片工具连续发生网络错误，没有把失败的图片生成结果作为交付；最终Logo为代码绘制、可重现的SVG作品，PNG由SVG渲染。

## 验证与限制

- Maven离线编译。
- Node语法检查Web脚本。
- 不连数据库的10项边界检查：未登录、角色隔离、跨站、路径逃逸、所有权、未审发布、审核中编辑、未审全提交、不相关题目审核。
- 浏览器检查19个字体图标及品牌预览。
- 本地启动后检查Web入口及未登录接口返回。
- 尚未用管理员/法务真实账号执行数据库写入或完整发布流程；没有为演示伪造或修改用户业务数据。
- 微信开发者工具中的真机/模拟器字体与布局需在已登录工具中再次确认。

验证脚本：`scripts/check_console_boundaries.ps1`，须先编译Java项目。视觉构建脚本：`build_yunjiang_icons.py`、`build_yunjiang_brand.ps1`、`render_yunjiang_brand.cjs`。品牌PS脚本请在PowerShell 7中执行，避免Windows PowerShell 5.1误读UTF-8中文。
