# 民族团结促进法学习系统
> 基于 Spring Boot + Vue 的普法学习管理系统，支持法规学习、趣味练习、AI 助教等功能。

## 项目结构
- **backend**：后端接口、业务逻辑、数据持久层
- **frontend**：前端页面、工具类
- **docs**：项目文档、需求说明

## 快速开始
1. 克隆项目：`git clone https://github.com/ChenYao-cpu/law-study-system.git`
2. 后端启动：进入 backend 目录，配置数据库，运行主类
3. 前端启动：进入 frontend 目录，安装依赖 `npm install`，运行 `npm run dev`

## 功能模块
- 首页：趣味练习、题库笔记、AI 助教
- 学习：法规原文、视频学习、进度统计
- 设置：个人中心、个性化配置
